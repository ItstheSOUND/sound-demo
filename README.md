# The SOUND demo

The live demo at demo.itsthesound.com. Netlify publishes this directory as it is on every push to master (no build step), so a push is a deploy.

What is here:

- `index.html` is the player: a hand-maintained single-page app with the platform's data embedded as `window.__SOUND_DATA__`. The data and the in-app calculator are refreshed from the platform by `Scripts/tools/refresh_demo_data.py`; the page's own rows and copy are edited by hand.
- `clips/` holds the 21 tone-bed clips the player plays, MP3, each named by its content hash. `img/` holds the hero photo as AVIF, WebP and JPEG, named the same way. Both are written by `Scripts/tools/demo_assets.py`, which derives them from the platform repository and rewrites the page's references; a changed file gets a new name, and `netlify.toml` caches these paths for a year.
- `what-your-plays-would-have-paid.html` is the artist calculator (also at `/plays`), generated by `Scripts/build_plays_calculator.py`.
- `share/` holds the link-preview cards, generated by `Scripts/build_share_cards.py`.
- `netlify.toml` carries the redirects and the cache rules.

Everything is client-side: seed data, gated payments, synthetic audio. Nothing here moves money.
